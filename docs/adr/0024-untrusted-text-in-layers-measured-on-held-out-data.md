# ADR-0024: Untrusted text in layers: trust the pixels, measure detectors on held-out data

- **Status:** Accepted
- **Date:** 2026-11-01

## Context

Two gaps in the injection defences (ADR-0012) had the same root: the system trusted
what a file *said* it contained. A scanned CV has no text layer, so it went through
ingestion empty and skipped every content check. A visible instruction written to
avoid the stock phrasing went unflagged. Whatever fixed the second needed a measurement
its designer couldn't game, because Finding 19 had already shown that a set written by
the person tuning against it says nothing.

## Decision

- **Trust the pixels, not the layers.** A page with an image and almost no visible text
  is read by Tesseract OCR, which returns character boxes, so citations still
  highlight. Any text layer already over the scan is ignored for that page. If it is
  invisible, it is reported as concealed text, whether scanner software added it or an
  attacker did. Documents read this way are labelled for reviewers.
- **Two layers for reworded instructions.** An offline detector flags sentences shaped
  like an instruction to an automated judge, and runs on every document for free. With a
  Gemini key, an embedding nearest-neighbour classifier adds an advisory second opinion
  on the sentences the rules missed. Neither removes text: flagged text stays in the
  document and is shown to the reviewer.
- **A held-out set decides what counts as detection.** The detector was tuned on a
  dev set its designer wrote. It was judged on a set generated by a model from a brief
  that never saw the rules, frozen before scoring and scored once (Finding 25). The
  embedding classifier was fitted on the dev set only.

## Rationale

The measurement changed the design. The rules scored 30/30 on their own set and 32/90 on
the held-out one. That justified keeping them, at nine times the recall of the patterns
with no false flags, but not trusting them alone. The classifier caught 80/90 but
flagged 9% of hard honest sentences, which is why it advises and never excludes.
Nothing honest is removed by either layer: excluding text is reserved for what a reader
cannot see, where the case is unambiguous.

## Consequences

- The held-out set has now been read, so it is a regression floor, not a target. Any
  claimed improvement needs a fresh set.
- The classifier's threshold is valid only for the embedding model it was fitted on, so
  it refuses any other. Changing the model means refitting.
- Instructions that steer by insinuation pass both layers. The control that holds
  regardless is still the prompt boundary: document text is quoted as data, and every
  verdict must cite.
- OCR confidence isn't recorded. The "Scanned" label is the signal reviewers get.
